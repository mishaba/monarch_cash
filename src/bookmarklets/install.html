Monarch DOM Analyzer
  1. Make sure your bookmarks bar is visible (Chrome: Ctrl+Shift+B / Cmd+Shift+B)
  2. Drag the blue button above onto your bookmarks bar
  3. Go to https://app.monarch.com/accounts
  4. Click the bookmark — a popup will open with DOM info
  5. Do the same on an account detail page
Note: If dragging doesn't work, right-click the blue button → Copy Link → then manually create a bookmark and paste it as the URL.
